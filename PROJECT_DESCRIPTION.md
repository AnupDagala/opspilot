# OpsPilot — CentrAlign AI engineering prototype

OpsPilot is a narrow support operations worker built with Python, FastAPI, SQLite and a responsive plain JavaScript dashboard. Its live OpenAI-compatible loop receives an operator goal, policies and validated tool schemas, chooses actions from tool results, and must read persisted ticket/draft/review state before an independent application verifier accepts the outcome. The same runtime supports processing billing/refund tickets, drafting without status changes, and read-only resolution audits. Code enforces approval boundaries, bounded execution, retry recovery, idempotency and explicit customer preference memory. Refunds awaiting approval are not completed work; human approval records only a simulated local CRM action.

Verified evidence includes 22 passing behavior tests, mocked-provider adaptation tests, a scripted seeded HTTP workflow and five scoped scripted goals, plus actual dashboard screenshots and a browser recording. **Genuine model-driven autonomy is not yet verified because API credentials were unavailable.** Scripted evidence is clearly labelled and is not presented as model reasoning. All customer data is fictional; no emails, payments or real account changes occur.
